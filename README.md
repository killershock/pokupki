# Покупки

Список покупок голосом: сказал «молоко, хлеб, сыр» — три пункта уже в списке.
Работает на айфоне как обычное приложение, данные хранятся в телефоне.

## Как поставить на iPhone

1. Открой в **Safari**: https://killershock.github.io/pokupki/
2. Кнопка «Поделиться» (квадрат со стрелкой вверх).
3. «На экран „Домой“» → «Добавить».

Дальше запускай с иконки — без адресной строки, работает без интернета.

## Как пользоваться

- **Говорить**: нажми и удерживай круглую кнопку, говори списком, отпусти.
- **Писать**: набери «молоко, хлеб, сыр» в строке и нажми Enter.
- **Количество**: «картошка 2 кг» → пункт «Картошка» с пометкой 2 кг.
- **Отметить купленное**: тап по кружку слева — пункт уходит вниз и зачёркивается.
- **Отправить**: кнопка «Отправить» — откроется меню «Поделиться» (Telegram, заметки).
- **Убрать купленное**: ссылка под списком.

## Что понимает

- Разделяет по запятым, «и», «плюс», с новой строки.
- Убирает «купить», «надо», «пожалуйста», «добавь».
- Понимает количество: кг, г, л, мл, шт, упак, пач, бутыл, банк, пакет.

## Данные

Хранятся в Safari на телефоне (localStorage), никуда не отправляются.
Если очистить данные сайта в Safari — список пропадёт.

## Если голос не работает

На iPhone распознавание речи в Safari иногда капризничает, особенно в режиме
«с экрана Домой». Ввод текстом работает всегда. Можно открыть сайт прямо в Safari
(не с иконки) — там распознавание обычно доступно.

## Технические детали

- Один файл `index.html` (HTML + CSS + JS), без сборки и зависимостей.
- `sw.js` — офлайн-режим, `manifest.webmanifest` — установка на экран.
- Иконки рисуются скриптом `icons/make-icons.ps1`.
- Локально: `Запустить-покупки.bat` → http://localhost:8092
